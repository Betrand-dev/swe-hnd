# Case Study Paper Overview

## Objective
The exam evaluates the candidate's abilities to:
* Apply an algorithmic procedure to analyze and propose a resolution of a problem.
* Translate algorithmic instructions into a structured, event, or object-oriented programming language.
* Analyze, design, develop, test, and implement relational database applications.
* Analyze, design, and implement UML Diagrams for a given software scenario or specifications.
* Master the basics of web design.
* Master the basic concepts of networks, network installation, administration, and administration of interconnected systems.

---

## Paper Content
* **Paper Name:** Case Study
* **Code:** SWE14
* **Nature of Exam:** Written
* **Duration:** 6 Hours
* **Credit Value:** 12
* **Structure:** The paper is compiled into a single 6-hour exam split into 4 distinct, timed sections: Algorithm and Programming, Database Development and Administration, Web Design, and Networking.

---

## What You Should Know
To successfully answer the questions in this paper, you must know:
* **Algorithms & Programming:** Core concepts of data structures, flowcharts, structural programming (C), event programming (VB.net), Object-Oriented Programming (C++ or Java), and system modeling using UML.
* **Database Management:** Relational database concepts, database design using the MERISE methodology, and writing structural SQL language queries.
* **Web Design & Architecture:** Frontend markup and styling using HTML5 and CSS3, client-side validation using JavaScript, and dynamic server-side logic using PHP, including direct PHP connection configurations to a MySQL database system.
* **Networking Foundations:** Network fundamentals, physical and logical topologies, network architectures, IP addressing schemes, subnetting calculations, and basic system/network administration.
