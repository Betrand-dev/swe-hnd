# System Analysis and Design Paper Overview

## Objective
The exam evaluates the candidate's structural capabilities to:
* Model object-oriented systems and application logic.
* Perform relational database administration tasks.
* Construct and design frontend and backend web application segments.
* Understand mobile terminal architectures and build applications for mobile environments.

---

## Paper Content
* **Paper Name:** System Analysis and Design
* **Code:** SWE11 
* **Nature of Exam:** Written
* **Duration:** 4 Hours
* **Credit Value:** 7
* **Structure:** The written paper is split into 2 primary testing parts: Section A covers information systems and databases, and Section B covers web and mobile programming.

---

## What You Should Know
To successfully answer the questions in this evaluation, you must master:
* **Object Modeling:** Unified Modeling Language (UML) architectures including structural and behavioral viewpoints, alongside meticulous class definitions (attributes, associations, aggregations, composition, generalizations, and parameterized classes) and Use Case scenarios.
* **Database Administration:** Core database objectives, maintaining ACID properties, writing structural definition scripts (creating databases, building tables), manipulating records (inserting, selecting data), and root user administrative profiling (creating accounts, assigning access rights, database backups) using MySQL.
* **Web Programming:** Internet network infrastructure definitions (web, intranet, extranet, and protocols), server communication loops, building responsive views with HTML5/CSS/JavaScript, and live backend connection pipelines through PHP.
* **Mobile Programming:** Architectural landscapes of mobile environments, physical terminal categorizations, internal handling of the Android Operating System, and designing tailored web applications deploying to mobile platform targets.
