# Computer Technology Paper Overview

## Objective
The exam evaluates the candidate's core understanding to:
* Understand the core concepts of software development and computer programming.
* Manage and manipulate data structure and algorithm parameters.
* Handle and process multimedia data processing elements.
* Operate and design basic network systems.
* Master the basics of web design.
* Master the basic concepts of networks, network installation, administration, and administration of interconnected systems.

---

## Paper Content
* **Paper Name:** Computer Technology
* **Code:** SWE15
* **Nature of Exam:** Written
* **Duration:** 3 Hours * (Note: Header specifies 4H, but total summary structure specifies 3H)*
* **Credit Value:** 4
* **Structure:** The written paper is split into two distinct testing parts: Section A consists of Multiple Choice Questions (MCQs), and Section B consists of structural/open-ended questions.

---

## What You Should Know
To successfully answer the questions in this evaluation, you must know:
* **Programming Languages & Structures:** Syntax and core paradigms of JavaScript, PHP, C, and Object-Oriented Programming in C++. You must know how to build flowcharts, analyze algorithms, work with structural data collections, and implement Object-Oriented Modeling (OOM) via UML.
* **Database Systems:** Theoretical database models, structural concepts, and execution of the SQL database syntax.
* **Web Design:** Core rendering mechanics of HTML5, stylesheet rule applications using CSS3, client-side functionality with JavaScript, backend scripting in PHP, and linking databases safely using MySQL connection states.
* **Computer Networking:** Fundamental network routing and protocols, logical topologies, hardware architecture, subnetting divisions, and local system administration frameworks.
