# Practice of Computer Paper Overview

## Objective
The practical exam evaluates the candidate's active engineering skills to:
* Apply an algorithmic procedure to analyze and propose a resolution of a problem.
* Translate algorithmic instructions into a structured, event, or object-oriented programming language.
* Analyze, design, develop, test, and implement relational database applications.
* Analyze, design, and implement UML Diagrams for a given software scenario or specifications.
* Master the basics of web design.
* Master the basic concepts of networks, network installation, administration, and administration of interconnected systems.

---

## Paper Content
* **Paper Name:** Practice of Computer
* **Code:** SWE17
* **Nature of Exam:** Practical
* **Duration:** 5 Hours
* **Credit Value:** 8
* **Structure:** A hands-on workstation examination consisting of 4 dedicated practical sections: Algorithm and Programming, Database Development and Administration, Web Design, and Networking.

---

## What You Should Know
To successfully clear the practical tasks, you must be able to execute:
* **Algorithm & Programming:** Real-time programming implementing data structures, structured code blocks in C, event-driven applications in VB.net, and object-oriented programming using C++ or Java. You are also tested on constructing Object-Oriented Modeling (OOM) via UML diagrams.
* **Database Development & Administration:** Setting up a live database environment. This includes schema normalization, database modeling and design, writing explicit SQL queries, and full implementation using MySQL as the Database Management System (DBMS).
* **Web Design:** Designing and coding visual web interfaces using HTML5 and CSS3, programming frontend logic with JavaScript, and scripting backend functionality using PHP with a live connection profile to a MySQL database.
* **Networking:** Working with network protocols, building architectures, arranging network topologies, calculating IP addressing / subnetting schemes, and completing tasks related to system and network administration.
